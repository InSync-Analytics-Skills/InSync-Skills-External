# Read-out discipline (chat only)

Referenced from SKILL.md Report.

**Read-out discipline (chat only, never added to the document).** The document narrative stays
strictly factual; the read-out you give the user is where the reasoning goes. For each of the
2–3 strongest setup reads: state the datum, its context (versus consensus, guide and the
company's own history), and the implication for the print — why it matters, what it means that
the number sits where it does. Cover the setup from both sides: the bull read and the bear read
of the same evidence, and which one the data actually supports. Close with the falsifier: name
the one datum that would prove the read wrong, and the key risks to it. Be specific, name the
metric and the number, and take a view the evidence supports rather than hedging.
