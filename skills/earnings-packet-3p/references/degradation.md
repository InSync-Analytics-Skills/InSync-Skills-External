# Degradation matrix, the remedies

The trigger conditions are indexed in SKILL.md. This file carries the remedy for each.
Read it when a run hits one of those conditions; it is not required for a clean build.

| situation | behaviour |
|---|---|
| Target quarter already reported | Refuse at Step 0, offer `earnings-wrap` |
| `resolve_grid` RAISES rather than returning a grid | Every raise is a coded outcome, not a crash. A message naming a target that has already reported IS the Step 0 refusal: offer `earnings-wrap`. A message about the calendar or the probe set means the window is too narrow: widen `get_call_date` and retry once, then report that no previewable event exists. Never work around a raise by falling back to the pointer, the input the module exists to distrust |
| `latest_fiscal_quarter` sits far behind the actuals | The issuer restated. Resolve `last_reported` from the call-date calendar and the actuals, never from the pointer; record the pointer and the resolved quarter in `warnings` |
| The restated band was caused by a STOCK SPLIT, not a spin-off or a segment change | Identical handling, and it is listed because the cause is not diagnostic: an operator reading the cause as the trigger may not recognise a split-driven `R-` band as the case the module already handles. Per-share history is re-presented on the new share count, so the affected labels carry the prefix exactly as a segment change does. Resolve from the calendar, normalise the labels, and name the split in `warnings` |
| `get_actuals` returns a period with an `R-` prefix | The VALUE is correct. Key the cell on the period REQUESTED, strip the prefix if you key on the response, and list the restated periods in `warnings`. Disclose in the section 3 note only where the restated band falls inside the packet window |
| BOTH a clean and a restated row arrive for one line item and period | The unprefixed row wins; the restated row is used only where it is the only row. Record the pair and check its Y/Y against the feed's `YOY_GROWTH`, because a clean base under a restated current quarter mixes two bases |
| Adjusted line absent | Reported used, asterisked, disclosed in the note |
| Adjusted valuation metric returns no rows | Non-adjusted used, asterisked in the row label and the note |
| `get_valuation` by CATEGORY returns zero rows for a category the issuer plainly has | The inverse of the case above, and measured: `Shareholder Returns` and `Market Valuation` came back empty on an issuer whose market cap, EV, FCF yield and dividend yield all exist, while the same metrics requested by EXPLICIT NAME returned them. Category-first is still the right default; on an empty return, re-request the same metrics by name before concluding there is no coverage, and record which form succeeded in `warnings`. Four of the twelve locked tiles come out of those two categories, so this lands on the headline strip |
| Line item returns no rows | Dropped at the Step 2 probe, listed in the report |
| Line has actuals but no forward consensus | Row kept; if no column can hold it, drop the row and say so |
| Segment feed absent | Section prints the drivers alone, never a blank table |
| Company does not guide at all | Guidance section says so; no empty grid |
| Company guides a measure other than EPS | `Guided EPS` tile reads `not guided`; the guided measure appears in section 2 |
| The sector drops net debt or EBITDA, and the locked tile strip still requires `leverage` | The formula is **net debt / LTM adjusted EBITDA**, stated here because the strip is locked and every run must use the same ratio. Where net debt is negative the tile reads `net cash`, not a negative multiple. For `banking` and `financials_nonbank`, which drop both terms, the tile is the issuer's own primary capital measure, CET1 % or the equivalent, labelled as such; for `insurance` it is debt to total capital. The tile is never blank and never silently repurposed: whatever stands in its place is named in the tile label |
| The sector has NO EBIT, and the locked tile strip requires `consensus EBIT` and `EBIT Y/Y` | `banking`, `financials_nonbank`, `insurance` and `reit` have no EBIT: the measure is undefined for them, not merely unpublished, so two of the six locked row 1 positions have no defined content. Take the named substitute from `sector-config.md` B12 (pre-provision net revenue then net income for a bank; underwriting result then net income for an insurer; FFO then AFFO then net income for a REIT), **label both tiles with the measure**, take BOTH from the same rung, and record the substitution and the rung in `warnings`. Where no rung returns a consensus the pair reads `not covered`. Without it a third of row 1 prints nothing on every bank packet. `check_contract.py` fails a tile labelled `EBIT` on those four keys |
| Guide is an approximation (`~4%`), or one value | Not parsed as a band; position is measured against the point within one unit of its last stated digit (`~4%` is 3 to 5; a value on the edge is at guide), and the note says so |
| Feed and release disagree on a guided range | Published release wins; the disagreement is disclosed in the note |
| The company guides a measure on ITS OWN definition and the feed carries a different one | Compare the guide with the consensus on the SAME basis, never across two. A company-defined free cash flow or an adjusted-EBITDA guide has its own consensus code; using the spine's code against the company's guide reports a beat or miss that neither party asserted. Record both bases in `margin_basis`, which is extended to guided items for exactly this, and state the basis in `notes.guidance`. Common in software, where the guided FCF margin is company-defined |
| Multiple outside the sector lens | Computed, held in `val_raw`, listed in `val_excluded`, not rendered in section 7 **or** section 8 |
| Multiple has no forward variant (P/B) | NTM cell left empty, never filled with the LTM figure; footnoted |
| Sector prefers a multiple the feed does not carry | Next multiple in the lens leads; the note states what was unavailable and why |
| Negative EPS, EBITDA or book value | That multiple is dropped with a reason in the cell; never `n/m`, never negative |
| The sector lens loses one or more multiples to a negative denominator | Refill from the pre-profit ladder in `sector-config.md` B10, in order, up to the count the sector lens held: EV/Sales, EV/Gross profit (Adj), P/B, then P/Sales and EV/IC. Skip a rung already in the lens and a rung whose own denominator is negative. A bank, an insurer or `financials_nonbank` takes P/B then P/Sales and stops, because enterprise value is undefined there. Where the ladder cannot fill to the count, print what exists and say in the note how many multiples the lens holds and why |
| `software_growth` confirmed, but the issuer publishes no ARR and no net revenue retention | The gate is satisfied by a NAMED code, and the spine follows that code: `sector-config.md` B9 substitutes remaining performance obligation, then billings, in place of ARR, with a Y/Y sub-row. Net revenue retention is DROPPED, never substituted: there is no second-best NRR. Where only deferred revenue codes, it moves to the drivers and the key falls back to `software_mature`. Name the satisfying code in `warnings` and the substituted measure in `notes.model` |
| Trailing average spans a loss period | Average printed but flagged not meaningful, or the distortion stated in the note |
| No 1y/3y history for a multiple | Row kept, averages read `no history` |
| Fewer than 3 usable peers | Section prints with what exists and says how many. The peer table sizes its grid to the row count at every size from 2 up, so a short set is a narrower table, never a short row inside a wide grid |
| A peer with an off-calendar year-end that has already reported returns no CY estimate for the packet's own calendar year | Normal, not a fetch gap: a July year-end that has reported returns the two FOLLOWING calendar years. Set the cell to null with a `<key>_note` of `not yet estimated`, which prints the phrase in grey, and say in `notes.peers_caveat` how many of the set are on a different fiscal calendar. Never substitute the peer's own fiscal year for a calendar year in a table headed calendarized |
| A row has no value in any column | Pruned in `T()`, named in the section note |
| A column is filled below `minFill` | Pruned in `T()`, the note states filled-of-total |
| A peer metric no peer codes | Row pruned; any note clause that depended on it is suppressed too |
| The feed carries ONE estimate contributor | Min, max and dispersion are null throughout and prune out of section 4; set `estimate_word` to `Estimate` so the masthead field and the section 2 column stop claiming a consensus; override the section 2, 3, 4 and 6 headings through `section_labels`; say so in pointer 1 |
| A default section heading is untrue for the issuer | Override title and subtitle through `section_labels`; never leave a heading that misdescribes its own table |
| A pruned row's label carries a unit prefix | `dropNote()` strips a short leading token before a middle dot, so the sentence reads `NTM P/E is not shown`, not `x  ·  NTM P/E is not shown` |
| Company publishes NO numeric guidance at all | `guide_vs_cons` is an empty array; section 2 prints its heading and `notes.guidance` and no table. Say in that note what the company does publish instead and where it is carried. Never a header row with nothing under it |
| Segments reconcile to the group exactly | The corporate-and-eliminations clause is suppressed; it prints only when some period carries at least $5M. Reconcile in `compute.py` and put the result in `warnings` |
| Issuer name too long for the masthead | The masthead steps its point size down through 14, 13.5, 13, 12.5 and 12pt (half-points 28, 27, 26, 25, 24). 12pt is a hard FLOOR: below it the two edges cannot both land on the one-line path, so the block takes the calibrated TWO-LINE path at 10pt with a balanced split chosen by the renderer, never by the layout engine. Measured, a name past roughly 40 characters goes two-line, and that is correct behaviour, not a defect: `self_check.py` asserts it. Never shorten the company name to make it fit |
| A peer comparability basis is identical across the set | The per-peer basis list is suppressed; the caveat sentence still prints. Five identical strings are an audit trail, not a disclosure |
| A Y/Y sub-row has a near-zero prior-year base | Drop the sub-row from `kpi_growth_sub`. A four-digit percentage is arithmetically true and analytically empty; the level row already carries the move |
| No revision vintage between two buckets | Use the vintages that exist, order the columns by real date, and say so in the note |
| A table will not fit the space left | Moves down whole; it does not spill its tail |
| A table exceeds `KEEP_MAX` rows | May split, but never leaving fewer than `MIN_BLOCK` rows either side |
| Packet runs to 4 pages | Compress by structure, never by deleting a section |
| No PDF converter | `.docx` ships, stated in the report |
